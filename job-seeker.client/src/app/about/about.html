About the Job Seeker

The Purpose

The purpose of this job seeker is to provide a means for myself and others to look for jobs in a programmatic way, as opposed to constantly having to sift through thousands of job postings online. The user provides keywords, salary, and other criteria related to the jobs that they are looking for. Then the job seeker searches the following sites for job postings that match their criteria.

We offer the ability to search on the following job boards (with even more in the works):

  • Indeed
  • LinkedIn
  • Ziprecruiter soon
  • Google Jobs soon
  • Glassdoor soon

The Tech

Under the hood, this site wraps around a Docker container running Playwright and JobSpy to search for jobs across an aggregate of sites. Criteria is stored in an Azure storage account, supplied to the aforementioned container app via a backend ASP.NET Core application.

Frontend
Angular 20, Bootstrap 5.3, CSS
Backend
.NET 10 ASP.NET Core, Python, Docker Containers
Hosting & Storage
Azure Container App Jobs, Azure Blob and Table Storage, Azure Web API

Source & Credits

This project is open source. Browse the code on GitHub.

  • Playwright — browser automation used to render and scrape job boards.
